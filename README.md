# Система обнаружения лесных пожаров

## 📝 Описание проекта
Проект использует предобученную модель для распознавания лесных пожаров на изображениях. Система позволяет:

- Классифицировать изображения как "пожар" или "нет пожара"
- Получать вероятность события
- Проверять сразу все изображения из папки

Проект направлен на разработку модели, способной помогать экологическим службам и пожарным в раннем обнаружении лесных пожаров с использованием CV (компьютерного зрения).

- Познакомиться с циклом разработки ML-driven решений
- Провести исследование, почитать туториалы и статьи

## 🛠️ Ключевые этапы работы

### 1. Настройка окружения
Установка необходимых библиотек:
pip install tensorflow numpy matplotlib pillow

### 2. Подготовка данных
- Разделение на тренировочный и валидационный набор  
- Нормализация и ресайз изображений до `(224, 224)`

### 3. Создание и дообучение модели
- Добавление слоев `GlobalAveragePooling2D + Dense(128) + Dense(1, sigmoid)`  
- Компиляция с `Adam` и loss=`binary_crossentropy`  
- Обучение модели на 10 эпохах  

### 4. Сохранение модели
- Модель сохраняется в формате `wildfire_model.h5`  

### 5. Проверка
- Функция `predict_wildfire(image_path)` для предсказания одного изображения  
- Функция `predict_folder(folder_path)` для проверки всех изображений из папки  

### 6. Документация и воспроизводимость
- Создание Jupyter Notebook с кодом обучения
- Подготовка функций для предсказаний и визуализации результатов


## ✨ Пример использования

### Для одного изображения:
predict_wildfire("test_images/test_image1.jpg")

Обнаружен пожар! Вероятность: 87%

### Для папки с изображениями:
predict_folder("test_images")
